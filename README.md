# NutriLog - Calorie & Macro Tracker

A lightweight, responsive calorie and macronutrient tracker built with vanilla HTML, CSS, and JavaScript. Zero external dependencies, no CSS variables, no Tailwind, and no backend needed—all data is stored persistently in the browser via `localStorage`.

## Features

- **Daily Calorie Budget & Status**: Dynamic SVG progress ring showing consumed vs. remaining calories with real-time budget status alerts.
- **Macronutrient Tracking**: Live progress bars tracking daily targets for Protein, Carbohydrates, and Fats.
- **Categorized Meal Logs**: Log foods under Breakfast, Lunch, Dinner, or Snacks with itemized calorie and macro breakdowns.
- **Food Presets Library**: Built-in library of common foods with serving multipliers for fast 1-click logging.
- **Custom Food Creation**: Create and save your own foods to your personal custom food library.
- **Hydration Tracker**: Interactive daily water tracker with customizable target glasses.
- **7-Day Trend Chart**: Pure HTML5 Canvas chart displaying weekly calorie intake against your daily target.
- **Customizable Goals**: Set custom daily calorie, macro, and water targets, or use 1-click presets (*Balanced*, *High Protein*, *Keto*).
- **Date Navigation**: Jump to past or future days using the native date picker or quick navigation buttons.
- **Backup & Restore**: Export your logs and settings as JSON or restore from an existing backup.

## Tech Stack

- **HTML5**: Semantic, accessible markup.
- **CSS3**: Pure vanilla CSS (clean system fonts, flexbox & grid, custom modal system, zero CSS variables).
- **JavaScript (ES6+)**: Pure client-side logic with `localStorage` persistence.

## Getting Started

Simply open `index.html` in any web browser—no server, build step, or installation required.
